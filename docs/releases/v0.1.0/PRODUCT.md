# 产品定义与验收 · v0.1

日期：2026-11-06（香港）

## 1. 目标与学习假设

原始构想来自用户指定聊天中的“期权积木”：用有限 Call、Put、现货与现金，在预算及风险约束下拼出收益结构，并区分到期损益和到期前估值。

目标用户是知道“看涨、看跌”但缺少组合直觉的期权学习者，以及需要向新人解释结构的交易员。核心任务不是记住六个策略名字，而是回答：组合在哪些价格赚钱、亏损边界在哪里、降低成本付出了什么代价。

待验证假设：玩家完成前两关后，能够解释卖出高执行价 Call 如何同时降低成本和封顶收益，并愿意在新任务里独立重建相似结构。这尚未通过用户研究验证。

建议首轮招募 5–8 位不同基础的学习者进行 20 分钟观察：不给口头教学，记录首次添加时间、理解成本的错误、首次检验结果、提示使用，以及事后能否用自己的话解释取舍。不要把“点过完成按钮”当作理解证明。

## 2. 核心闭环

进入任务 → 阅读预算与风险条件 → 选择工具与买卖方向 → 观察曲线 → 调整数量或执行价 → 检验全部条件 → 读懂情景复盘 → 再试或下一关。

自由实验允许最多 8 单位，不评分；经典示范只载入组合，不宣称过关。所有挑战可直接选择，方便教学演示与重复实验。

## 3. 关卡设计

| 关卡 | 工具与上限 | 核心检查 | 学习结果 |
|---|---|---|---|
| 给上涨一个机会 | Call，只买，1 单位 | 支出≤6；损失≤6；P&L(120)≥10 | 权利金与盈亏平衡 |
| 用取舍换预算 | Call，可买卖，2 单位 | 支出≤3.6；损失≤3.6；P&L(120)≥6 | 收益封顶补贴成本 |
| 安全带 | 现货与 Put，只买，2 单位 | 支出≤102；损失≤12；P&L(120)≥17 | 下行保险不是免费 |
| 波动可期 | Call / Put，只买，2 单位 | 支出≤10；损失≤10；P&L(80/120)≥10 | 双向机会需要足够波动 |
| 收益留在中间 | Call，可买卖，4 单位 | 支出/损失≤5；P&L(100)≥5.5；P&L(80/120)≥−5 | 收益集中与区间风险 |
| 领口 | 现货 / Call / Put，3 单位 | 支出≤101；损失≤11；P&L(120)≥9 | 两侧边界与成本权衡 |

执行价与示范方案以 `dist/js/levels.js` 为唯一数据源；任何满足条件的合法组合都能过关，不要求匹配策略名称或逐腿匹配示范。

## 4. 评分规则

- 合法性：非空、整数非零数量、可用工具、可用执行价、允许的方向、总绝对数量上限。
- 必须满足全部任务条件。数字显示保留两位，但判题使用未四舍五入数值与 1e−6 容差。
- 到期前滑块和参考轮廓不改变判题。失败反馈显示未满足条件及实际数值，不自动揭示解法。
- 独立完成 3 星；使用文字提示后最多 2 星；载入示范后最多 1 星。历史成绩只提高、不降低。
- 本次提示状态随草稿保存；切关与刷新不清除。确认清空组合后开始新一次尝试。
- 参考轮廓是低门槛脚手架；现版星级不是经验证的能力量表。后续增加关闭参考的迁移题才能观察独立理解。

## 5. 验收标准

1. 第一次进入看到任务、参考曲线、可用积木与空组合；检验按钮禁用。
2. 点击或拖入合法工具即更新曲线、成本与风险；超量操作不能改变持仓。
3. 同工具与执行价按数量净额合并；相反方向相互抵销；费用按最终净持仓计。
4. 最大损失不使用图表采样近似；裸卖 Call 与空现货正确显示无限风险。
5. 切换到期前估值后，建仓价格不随 IV / 天数变化；评分仍以到期为准。
6. 六个示范均可解；空组合及违规组合不能过关。
7. 成功显示逐条条件、实际值、三情景、成本及教学解释。
8. 草稿、完成星级与提示记录刷新后恢复；损坏或不可用存储不导致白屏。
9. 手机可完成点击式全流程；拖拽不是唯一操作方式。
10. 未来游戏明确标记“未来计划”，点击展示构想而非不可用的开始按钮。

## 6. 首版范围

本版不建立账号、排行榜、付费、多人、真实行情或真实下单，不引入大语言模型负责数值核算。没有服务端反作弊；星星只用于个人学习。后续如加入排行榜，必须服务端重新判题。

## 7. 后续体验建议

在第二关增加一次“先预测”选择：卖出 K110 Call 会改变成本、右侧斜率还是两者？作答后再让玩家操作。让复盘解释预测与结果的差异。

做小幅参数扰动的迁移题：换初始价格、预算和执行价，不直接复制原题。先验证理解是否迁移，再增加关卡数量。保留自由实验作为低压力探索空间。
