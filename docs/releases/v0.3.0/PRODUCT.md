# 产品与验收标准 · 平台 v0.3.0

日期：2026-11-06（香港）。本版包含期权积木 v0.3 与波动率捕手 v0.1；两款独立玩法，共用定价函数、界面外壳与发布流程。

## 目标与范围变化

期权积木从静态练习拓展到可校验、可导入和可分享的课程内容。波动率捕手建立“当前信息—决策—成交—时间推进—重估—复盘”的完整闭环。

原聊天最新建议先做结构化产品工坊再做 Gamma Surfer；本轮用户明确要求开发波动率捕手，因此本版将动态游戏提前，产品工坊继续列为后续方向。v0.2.1 用户观察尚未执行，不把功能交付当作教学效果已获验证。

## 期权积木 v0.3

保留六个基础关、三个迁移关、首次预测、撤销/重做、回放和星级。新增课程工坊、三题示例、JSON 模板、课程导入/导出、分享链接、学习记录合并预览，以及对照曲线叠加。

课程规则是封闭 schema：1–12 题，单题最多 8 单位、7 个执行价；只允许 Call、Put、现货与面值 $10 的现金，乘数 1。市场参数、任务条件与参考解均需校验。普通任务须有通过全部条件的参考解；无解任务仅允许最多 2 类工具、3 个执行价、2 单位，通过完整离散枚举证明。不是对任意合约空间的不可行证明。

三题示例：预算内价差；用 Call − Put + K 现金复制现货支付；工具有限且约束冲突的不可能订单。支付图与净损益图分开；完整风险仍解析检查 S=0、全部执行价与右端斜率。

分享链接只携带任务与持仓，载入前须确认，不携带个人学习记录、不改变私密网站权限。接收后的组合按示范辅助计分，且必须重新判题。课程替换保留旧进度；内容变化使用不同任务标识。

学习记录导入支持旧导出版本 1/2 和本版版本 3。只重新核算并合并较高星级，填补空草稿；保留已有非空草稿、首次预测和另一游戏数据。课程包先单独载入，才识别其中的任务进度。导入不是全量账号恢复或跨设备同步。

## 波动率捕手 v0.1

六个场景：往返与相同终点、平静与时间流逝、IV 下跌、价格跳跃、近到期结算、未知种子路径。五条已见路径可反复练习；未知挑战每次生成新种子，界面仅展示已观察到的价格。

每局八个决策回合。初始资本 $10,000；持有一份 K100 Call 和一份 Put，每腿乘数 100，不能中途删减指定期权。可以选择调至 Delta 中性、减半净 Delta、保持仓位；每回合只可执行一次，再推进一天。

标准场景初始 30 天、IV 60%；近到期场景从八天开始，IV 退潮场景每步下降 3.5 个百分点，末步到 32%。所有金额美元，ACT/365、r=q=0、欧式现金结算。允许小数单位标的，标的仓位上限 200 单位。无保证金、强平或额外融资成本。

标的费率 5bps、半价差 5bps；期权按总价值在开仓和提前退出各收 5bps，到期现金结算不收期权退出费。费用和价差分列入现金。第八步强制平掉标的，并退出或到期结算期权。

复盘使用实际现金流水和完整期权重估；对照不对冲、每两天对冲、净 Delta 超过 15 时对冲三种基准。显示净盈亏、成本、决策后最大 |Delta|、区间遵守率和观察点回撤，不按盈利排名。Greeks 近似分解保留残差，不能重复加到真实盈亏里。

保存当前种子和决策序列，可恢复尚未推进的决策而不重复成交。最近 12 局摘要重新播放核算；支持本局账本/回合记录查看和 JSON 导出。未实现 Gamma 外部记录导入、任意数量对冲、规则编辑或云端排行榜。

## 效果验证与边界

本版没有开展正式用户研究、专业能力测评、全面屏幕阅读器或跨浏览器认证。客户端题库和路径可被技术性查看，不提供防作弊承诺。新增内容需要先让 5–8 位学习者操作，再决定加关卡还是改善反馈。
