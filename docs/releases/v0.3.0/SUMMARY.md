# v0.3.0 发布总结

日期：2026-11-06（香港）。平台版本 0.3.0，包含期权积木 v0.3 与波动率捕手 v0.1。

## 目标与交付

期权积木从练习工具升级为可校验的内容平台：课程模板、封闭 schema、参考解验收、有限枚举无解证明、导入预览、分享与辅助计分、记录保守合并、支付图和对照叠加。

波动率捕手交付六个短场景、三种对冲动作、八回合公平时序、完整现金账本、最终退出/到期结算、三基准、Greeks 解释与残差、种子重放、恢复、最近训练与本局导出。

公共外壳与路由抽离，独立游戏事件生命周期及存储。未新增第三方运行依赖。按本轮用户明确要求把 Gamma 提前，结构化产品工坊仍为后续方向。

## 验收证据

60 项自动检查通过；完整浏览器实玩、课程/分享/导入及手机布局的范围以 QA 为准。原聊天 100→110→100 的成本前 368.18 算例已复现。每条基准在同一费用下重新计算，费用只记一次。

## 兼容与限制

保留 v0.1/v0.2 的记录和冻结档案。Payoff 存储为向后兼容附加字段，导出 envelope 版本 3；Gamma 独立 schema 1。导入只合并较高成绩并填补空草稿，不覆盖预测或其他游戏。客户端数据不能当作可信竞赛成绩。

未完成用户研究、可视化编辑器、多课程收藏、云同步、Gamma 外部记录导入、任意交易规则、融资/保证金或真实市场连接。分享不改变网站的私密权限。
