# 课程、分享与记录格式 · v0.3

课程模板：`dist/courses/starter.json`。网页课程工坊可下载模板、粘贴 JSON 或选择本地文件。编辑方式是 JSON，尚非可视化关卡编辑器。

## 课程包

```json
{"format":"arcade-course","version":1,"id":"custom-my-course","title":"我的课程","lessons":[]}
```

实际 lessons 必须为 1–12 道完整任务。每题字段：id/title/topic/brief/hint/lesson、types/strikes/sell/maxUnits、market、goals，以及 solution 或 infeasible。

- ID 只使用 custom- 前缀与小写字母/数字/短横线，包内不可重复。
- 工具只有 call/put/stock/cash；最多 7 个执行价，最多 8 个整数净持仓单位；现金每单位 $10。
- 市场 spot 为 10–500，days 为 1–365，vol 为 0.05–2，fee 为 0–20，multiplier 仅为 1。
- goals 为 1–12 条；kind 仅允许 debit/loss/scenario/payoff/tailSlope；op 仅允许 gte/lte；limit 为有限数，情景价格有限且非负。不执行公式表达式。
- 普通任务必须有非空合法 solution，完整判题通过才可载入。
- infeasible=true 的题不带 solution；限定最多 2 类工具、3 执行价、2 单位，完整枚举确无可行解才能载入。
- 未知字段、原型保留键、超长文本、非法执行价、数量、枚举或非有限数被拒绝。

载入前展示预览。一份浏览器当前载入一组课程包，替换不会删旧进度。运行时根据规范化题目内容产生稳定任务标识；题目语义改变后不沿用旧成绩。该标识用于区分内容，不是数字签名或服务器反作弊。

## 组合分享

URL fragment `#share=<base64url UTF-8 JSON>`，格式为 arcade-combo、版本 1，只包含合法任务和非空持仓。编码长度上限 18,000 字符，接收时再次校验 schema、参考解和工具约束。不能携带脚本、未知模型或任意代码。

接收者先确认内容和替换课程的影响；持仓按示范辅助载入，完成仍须重新判题。分享不携带个人进度，不改变网站访问权限；私有网站的接收者仍须有访问权。

## 学习记录导入

文件字节上限 250,000；支持旧版本 1/2 和新版 3 的期权积木导出对象。只识别内置题及当前载入课程的任务，完成记录需要合法持仓及重新判题；无解题重做完整枚举，不信任外部证书或分数。

合并较高星级，并填入原来为空的草稿。既有非空草稿、首次预测、未知课程进度和 Gamma 存储不覆盖。不提供“全量替换账号”操作；当前仍无账号云同步。

## 边界

题库、参考解和模拟路径都在客户端，适合教学与个人实验，不作为可信竞赛服务器。外部文字按文本转义显示；HTML 字符不是执行授权。未来开放更多乘数、bid/ask、不同期限与产品条款时须升级格式与验收规则。
