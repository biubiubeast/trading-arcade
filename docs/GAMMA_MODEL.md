# 波动率捕手 v0.2 · 金融模型与核算

规则版本 2，平台 v0.4 引入可编辑规则与多路径实验；默认交易费用及原有价格路径不变。使用合成教学市场，不连接真实行情或交易。

## 合约、单位与时钟

初始资金 10,000 美元；Call 与 Put 各一张，执行价 100，每腿乘数 100。期权报价与市值显示为两腿总美元价值；标的按可带小数的单位交易。ACT/365、零利率、零股息、欧式现金结算。

Delta 为标的单位；Gamma 为标的价格每变化 1 美元时 Delta 的变化；Vega 为 IV 变化 1 个百分点的美元影响；Theta 为时间经过一天的美元影响。已结算后所有持仓为零，因此 Greeks 为零。

显示当前状态 → 接收一个动作 → 按当前报价执行 → 推进一天 → 完整重估。相同回合不能重复下单，不能见到新价格后按旧价格成交。自动退出仅发生在最后一步。

## 账户与成交

E = B + hS + V。初始买入两腿期权：B₀ = 10,000 − V₀ − optionEntryFee。

标的数量变化 q：

```text
stockFee = |q| × S × 0.0005
halfSpreadCost = |q| × S × 0.0005
B_after = B_before − q × S − stockFee − halfSpreadCost
h_after = h_before + q
```

等价于标的按买入 ask / 卖出 bid 成交，再扣手续费。账本保留中间价现金流并单列价差，不重复扣价差。期权开仓与提前退出按总价值收取 5bps 费率，不另设期权 bid/ask；到期结算不收期权退出费。

最后一步：平掉全部标的，扣标的费用与价差；期权若未到期按完整 BS 价值卖出并扣费，若到期按内在价值现金结算。现金可能因交易为负，模型按零利率融资；没有把保证金占用当费用。

## 盈亏与近似解释

```text
netPnL = (finalOptionValue − initialOptionValue)
       + Σ h_beforeInterval × ΔS
       − allFees − allHalfSpreadCosts
```

最终全部持仓清空后，netPnL 必须等于 finalCash − initialCapital。

每段解释使用前一观察点的组合总 Greeks：方向项 DΔS、Gamma 项 0.5Γ(ΔS)²、Vega 项 ν×ΔIV(pp)、Theta 项 θ×经过天数。完整市场重估变化减去这些项得到残差。四项加残差合计为成本前变化，再扣成本一次等于净盈亏；不能在已核算的 P&L 上另加 Gamma 收益。

大幅跳跃、IV 大变化和近到期时残差可能较大，这正是教学内容，不通过人为归零掩盖。

固定 IV 60%，30 天起步，100→110→100，两次调至中性，第二天退出；先把成本设为零：

| -------------- | ----------: |
| 初始跨式价值   | 1370.790789 |

| 期权价值变化   |  −46.372188 |
| 标的对冲毛盈亏 | +414.550435 |

## 基准与观察指标

不对冲：所有中间决策保持；每两天对冲：第 0/2/4/6 步调至中性；阈值对冲：当前 |净 Delta|>15 才调至中性。三者均强制最终平仓，并使用相同种子、期权和成本规则。

区间遵守率只指每次决策后、下一段市场开始前 |Delta|≤15 的比例；不是连续时间风险控制认证。最大 |Delta|同样基于这些决策后点。最大回撤基于观察到的权益序列，不能称为日内最大回撤。回合列表是退出前重估，最终平仓与期权退出成本另外计入账户和账本。

盈利可能伴随较大方向风险，亏损也可能来自合理持仓承受的时间与 IV 变化，因此不按净盈亏生成能力排名。

## v0.2 可配置规则与批次评估

四个白名单参数：threshold=1–100 标的单位，interval=1–4 整数天，feeBps/spreadBps=0–50。默认 15/2/5/5，转换为 engineConfig 后在新局建仓时锁定。手续费仍用于期权开仓/提前退出及标的成交，半价差仅用于标的。到期期权退出费为零。风险遵守率与阈值策略使用同一个锁定 threshold，定时策略从索引 0 开始每 interval 天中性对冲。

每次多路径评估生成 32 个不同种子，未知路径为年化 65% 波动的几何布朗运动、期望漂移零，定价 IV 固定 60%，八步。三个策略共享所有种子及费用；每条路径均强制结算。分位数按排序后的线性插值计算，P10 不是最坏可能损失。观察点回撤、决策后风险、成本各自列出，不合成为盈利排名。

成本敏感性在同一路径/阈值下把费率和半价差乘 0/1/2，包含初始及最终退出，2× 可超过 UI 单一基础费率的 50bps 上限。交易决策不以盈亏为输入，因而相同策略下成本前对冲收益保持一致，均值盈亏差恰等于增量成本；不同路径的分位数差不应误说成某一条交易的费用差。
